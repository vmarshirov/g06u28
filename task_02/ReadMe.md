## Разработка адаптивного сайта на основе CSS и JS
### Создать логически связанную и завершенную информационную среду (сайт) оригинальной тематической направленности, содержащий перечисленные ниже элементы и особенности. Элементы и атрибуты классического HTML избегать (по-возможности использовать стили)
####	Единую для всех страниц навигационную часть, имеющую:
1.	Показывающию посетителю его текущее положение выделением в навигации
#### Информационные страницы (3-6), которые должны содержать:
2.	Навигацию внутри страницы (раздел 1, раздел 2, к началу страницы )  с использование закладок;

3-4.	Страницу с частично повторяющимся контентом (блоками), 6-12 повторений. Оригинальные данные считывать из файла

5-8.	Страница о студенте который защищает контрольную и о его образовательной программе  (с <b>реальными данными</b>, которые считываются из файла) должна содержать: 
- описание образовательной программы и ссылку на сайт образовательной программы
- информацию о студенте(фото, ФИО, электронка, ссылки на контрольную 1 и контрольную 2)
- информацию о руководителе образовательной программы (фото, ФИО, электронка, ссылка на страницу)
- информацию о менеджере  образовательной программы (фото, ФИО, электронка, ссылка на страницу)

#### Cайт также должен содержать:
9.	Страницу с работающей формой для отправки на удаленный сервер оригинальных данных (заказы из магазина, отзывы на что-либо, или другое, относящееся к тематике сайта и удовлетворяющую условиям:
  - названия переменных (атрибут - name) должны соответствовать решаемой задаче.
  - форма должна обязательно содержать следующие типы: text, number, radio
  - форма отправляет на удаленный сервер не "пустые" значения по-умолчанию.

#### При оценивании этой контрольной работы учитывается:
10. Размещение оцениваемых материалов на удаленном сервере.

11-12. Адаптивная верстка сайта и его страниц, обеспечивающая корректное отображение сайта на всех устройствах (десктоп, планшет, смартфон).
