# 090_bootstrap — учебный сайт на Bootstrap 5

Демо: https://vmarshirov.github.io/g06u28/020_css/090_bootstrap/

Небольшой многостраничный сайт: общая шапка, вкладки навигации, подвал и три страницы.

## Структура проекта

| Файл / папка        | Назначение |
|---------------------|------------|
| `index.html`        | Первая страница: якорные ссылки между разделами |
| `shop.html`         | Магазин: карточки товаров строятся скриптом из JSON |
| `form.html`         | Пример формы на компонентах Bootstrap |
| `index.css`         | Собственные стили (отступы заголовков, демо media query) |
| `js/0650_api.js`    | Загрузка `data/shop.json` и вывод карточек товаров |
| `data/shop.json`    | Каталог товаров (11 шт., на странице показываются первые 9) |
| `data/0620.json`    | Учебные данные, сейчас нигде не используются |
| `images/`           | Изображения (используются `background.jpg`, `uso_001–005.jpg`, `1_1–1_6.png`) |

## Запуск

Страница магазина загружает данные через `fetch`, поэтому открывать её нужно через HTTP-сервер,
а не двойным кликом по файлу. Самый простой способ — расширение **Live Server** для VS Code
или команда `python3 -m http.server` в папке проекта (затем http://localhost:8000).

## Формат товара в `data/shop.json`

```json
{
  "id": "1",
  "title": "Товар 1",
  "vendor_code": "111",
  "description": "Описание 1",
  "price": 100,
  "img": "./images/uso_001.jpg"
}
```

Путь `img` указывается относительно страницы `shop.html`, а не файла JSON.
